# Pega Ticketing and Booking Application

## Project Description

This project is developed using Pega for managing ticketing and booking requests.

## Technologies Used

* Pega Case Management
* Pega UI

## Features

* Create Ticket
* Ticket Management

* Case Processing
* Status Tracking
